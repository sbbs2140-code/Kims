# 수업 관찰 기록 (Google Apps Script 판)

`public/observation/index.html`(브라우저 저장판)을 구글 앱스 스크립트 웹앱으로 옮긴 것임.
기록은 스크립트가 연결된 **구글 시트**에 저장되므로 학교 PC, 노트북, 휴대폰 어디서 열어도 같은 기록이 보임.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 코드. 시트 읽기·쓰기, 웹앱 열기 |
| `index.html` | 화면(HTML·CSS·JavaScript) |
| `appsscript.json` | 설정(시간대, 웹앱 접근 권한). 선택 사항 |

## 설치 방법 (약 5분)

1. **구글 시트 만들기**: 구글 드라이브 → 새로 만들기 → Google 스프레드시트. 이름 예: `수업관찰기록_2026`
2. **스크립트 편집기 열기**: 시트 메뉴 **확장 프로그램 → Apps Script**
3. **Code.gs 붙여넣기**: 왼쪽 `Code.gs`의 내용을 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣음
4. **index.html 추가**: 파일 옆 **+ → HTML** → 이름을 `index`로 입력(.html은 자동으로 붙음) → 이 폴더의 `index.html` 내용을 붙여넣음
5. **저장**: Ctrl+S
6. **배포**: 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** (학생 개인정보가 담기므로 반드시 "나만"으로 둠)
7. **권한 승인**: "액세스 승인" → 본인 계정 선택 → "고급" → "(프로젝트 이름)(으)로 이동" → 허용
   - 본인이 만든 스크립트라 "확인되지 않은 앱" 경고가 나오며, 정상임.
   - 요청 권한은 "이 스프레드시트만 보기·수정"으로 좁혀 두었음(`@OnlyCurrentDoc`).
8. 배포 화면에 나온 **웹 앱 URL**을 열어 사용함. 휴대폰에서는 이 주소를 홈 화면에 추가하면 앱처럼 열림.

처음 기록을 저장하면 시트에 `관찰기록`, `수업성찰` 탭이 자동으로 생김.

## 코드를 고친 뒤

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 웹앱 주소에 반영됨.
(같은 주소가 유지됨. "새 배포"를 누르면 주소가 바뀌므로 주의)

## 기존 브라우저 저장판 기록 옮기기

1. 기존 앱(`/observation/index.html`)의 **데이터 → JSON 내려받기**
2. GAS 웹앱의 **데이터 → JSON 불러오기 → 합치기**에서 그 파일 선택

## 알아 둘 점

- 시트를 직접 고쳐도 됨. 다만 **A열(ID)과 1행(제목)은 지우거나 바꾸지 말 것.** 날짜는 `2026-10-04` 형식을 유지해야 함.
- 저장할 때마다 서버를 거치므로 1~2초 정도 걸림. 저장 중에는 버튼이 "저장 중…"으로 바뀌고 다시 눌리지 않음.
- 학생별 텍스트·JSON 내려받기는 웹앱 화면 안에서 동작하도록 만들었으나, 구글 웹앱 보안 설정상 브라우저에 따라 막힐 수 있음(확인 필요). 막히면 구글 시트의 **파일 → 다운로드**로 대신 받을 수 있음.
- 시트 자체가 원본이므로 시트를 지우면 기록도 사라짐. 학기 말에는 JSON 내려받기나 시트 사본 만들기로 보관을 권함.
