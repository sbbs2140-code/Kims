# 수업 관찰 기록 v2 (Google Apps Script)

수업 중 학생 관찰, 수행평가 채점, 수업 성찰을 기록하는 교사용 웹앱임.
기록은 스크립트가 연결된 **구글 시트**에 저장되므로 학교 PC, 노트북, 휴대폰 어디서 열어도 같은 기록이 보임.

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 코드. 시트 읽기·쓰기 |
| `index.html` | 화면 전체(HTML·CSS·JavaScript). 파일만 열면 체험 모드로 동작 |
| `appsscript.json` | 설정(시간대, 웹앱 접근 권한 "나만"). 선택 사항 |
| `prototype.html`, `dashboard.html` | 디자인 시안(참고용) |

## 1. 설치 (약 5분)

1. 구글 드라이브 → 새로 만들기 → **Google 스프레드시트**. 이름 예: `수업관찰기록_2026`
2. 시트 메뉴 **확장 프로그램 → Apps Script**
3. `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs`를 붙여넣음
4. 파일 옆 **+ → HTML** → 이름 `index` → 이 폴더의 `index.html`을 붙여넣음
5. **저장**(Ctrl+S)
6. **배포 → 새 배포 → 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** (학생 개인정보가 담기므로 반드시 "나만")
7. **액세스 승인** → 계정 선택 → "고급" → "(프로젝트)(으)로 이동" → 허용
   - 직접 만든 스크립트라 "확인되지 않은 앱" 경고가 나오며 정상임
   - 권한은 "이 스프레드시트만"으로 좁혀 두었음(`@OnlyCurrentDoc`)
8. 나온 **웹 앱 URL**로 접속. 휴대폰은 이 주소를 홈 화면에 추가하면 앱처럼 열림

처음 열면 시트에 `학급`, `학생`, `관찰기록`, `수행평가`, `채점`, `수업성찰`, `빠른문구` 탭이 자동으로 생김.

## 2. 처음 준비

1. **설정 → 학급 추가**: 학급(예: 2-3)과 교과(예: 한문)
2. **명단**: 한 줄에 `번호 이름`. 엑셀·나이스에서 번호와 이름 두 칸을 복사해 붙여넣어도 됨
3. **평가 → 새 평가**: 평가 이름, 평가일, 채점 기준(기준마다 5단계). 여러 학급에 한 번에 만들 수 있음

## 3. 화면 요약

| 화면 | 하는 일 |
|---|---|
| 홈 | 이번 주 관찰 수, 채점 진행률, 요일별 관찰 차트, 할 일(누르면 해당 화면으로 이동) |
| 수업 | 학생 카드 선택(여러 명 가능) → 영역·구분·빠른 문구 → 저장. 저장 직후 되돌리기 가능 |
| 평가 | 수준 버튼으로 채점, 결시·미제출은 기본 점수, 저장하면 다음 미채점 학생으로 이동, 점수표 CSV |
| 일지 | 학급·날짜·영역·구분·검색으로 조회, 수정·삭제 |
| 학생 | 관찰 기록과 수행평가를 시간순으로 모아 봄, 텍스트로 내려받기·복사 |
| 성찰 | 날짜별 수업 성찰 4문항, 그날 관찰 요약과 지도 필요 학생 자동 채움 |
| 설정 | 학급·명단, 빠른 문구, JSON 내려받기·합치기·바꾸기, 전체 삭제 |

## 4. 알아 둘 점

- **저장 방식**: 기록은 화면에 먼저 나타나고 뒤에서 시트에 저장됨. 위쪽 표시가 "저장됨"이면 시트까지 저장된 것임.
  인터넷이 끊기면 "대기 n"으로 바뀌고 연결되면 자동으로 다시 저장함. 대기 중인 기록은 그 브라우저에 잠시 보관됨.
- **명단에서 빠진 학생**은 지우지 않고 "재적 해제"로 바꿔 기록을 남김. 명단에 다시 넣으면 돌아옴.
- **학급 삭제**는 그 학급의 학생·관찰·평가·채점·성찰을 모두 지움(학급 이름을 입력해야 지워짐).
- **결시·미제출 기본 점수**는 기본값이 각 기준 최저 점수의 합이며, 평가 수정에서 바꿀 수 있음. 실제 기준은 학교 학업성적관리규정을 따름.
- **이미 채점한 평가**는 기준 개수를 바꿀 수 없음. 기준 이름·점수·설명은 고칠 수 있고 합계는 다시 계산됨.
- **시트를 직접 고칠 때**: 1행(제목)과 ID 열은 바꾸지 말 것. 날짜는 `2026-10-04` 형식 유지.
- **내려받기(텍스트·CSV·JSON)**는 구글 웹앱 보안 설정에 따라 브라우저에서 막힐 수 있음(확인 필요).
  막히면 학생 화면의 "내용 보기·복사"를 쓰거나 시트에서 **파일 → 다운로드**를 쓰면 됨.
- **v1(브라우저 저장판) 기록 옮기기**: v1에서 JSON 내려받기 → v2 **설정 → JSON 합치기**. 교과 영역 이름이 학급 이름으로, 학생 이름은 그 학급 명단과 맞춰 들어감.

## 5. 문제 해결: "다음 스크립트 함수(doGet)를 찾을 수 없습니다"

위에서부터 차례로 확인함.

1. **저장한 뒤 배포했는지**: 배포는 그 순간의 저장본을 고정함. 코드를 붙여넣고 저장하기 전에 배포했다면,
   저장(Ctrl+S) 후 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 다시 함.
2. **Code.gs에 기본 코드가 남아 있는지**: `function myFunction() {}`만 있거나 붙여넣기가 덜 되었으면 doGet이 없음.
   Code.gs 전체를 지우고 다시 붙여넣은 뒤 저장함.
3. **index.html과 Code.gs를 바꿔 붙였는지**: Code.gs 첫 줄은 `/**`, index 파일 첫 줄은 `<!doctype html>`이어야 함.
4. **같은 프로젝트에 다른 .gs 파일이 있는지**: v1 코드나 다른 코드가 함께 있으면 doGet이 겹침.
   v2는 **새 구글 시트에서 새 Apps Script 프로젝트**로 만드는 것을 권장함.
5. **편집기에서 점검 실행**: 위쪽 함수 목록에서 `checkSetup`을 고르고 [실행] → 권한 허용.
   실행 로그에 "점검 완료"가 나오면 코드는 정상이므로 1번(새 버전 배포)을 다시 함.
   함수 목록에 `checkSetup`·`doGet`이 보이지 않으면 저장이 안 되었거나 붙여넣기에 문제가 있는 것임.

## 6. 코드를 고친 뒤

**배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. ("새 배포"를 누르면 주소가 바뀜)

## 7. 미리 보기

`index.html`을 브라우저로 바로 열면 **체험 모드**(예시 가명 데이터, 새로고침하면 초기화)로 모든 화면을 눌러 볼 수 있음.
