# 시험 감독 배정 웹앱 계획

인터뷰(grilling)로 합의한 내용을 정리한 문서임. 코드는 아직 작성하지 않음.

## 1. 규모
- 학년당 11반, 3개 학년, 총 33학급
- 감독 대상 교사 약 60명 (관리자 제외, 명단은 앱에서 추가·삭제·수정)
- 하루 3교시, 중간고사 3일, 기말고사 4일

## 2. 입력
- 시험 시간표(날짜, 교시, 학년, 시험 또는 자율, 과목, 시험실)를 엑셀·구글시트에서 복사해 붙여넣음
- 교시마다 학년별로 시험 또는 자율을 지정함 (시험 1개 학년 + 자율 2개 학년, 또는 시험 2개 학년 + 자율 1개 학년)
- 필요 인원을 자동 계산하고, 교사가 부족하면 편성 전에 경고함
- 교사 정보: 이름, 담임 학급, 출제 교과, 불가 교시(연수·출장·휴가 등)

## 3. 역할과 인원
- 시험실마다 정감독 1명 + 부감독 1명
- 자율학습(시험 없는 학년)은 학급당 1명, 장소는 선택 입력. 시험 2개 학년 + 자율 1개 학년인 교시는 55명이 필요하므로 교사 60명 기준으로 편성함

## 4. 공정성 규칙
- 점수(설정값, 코드 수정 없이 변경): 정감독 1.0 / 부감독 0.8 / 자율 0.5
- 교사별 점수 합계 차이를 최소화함. 정감독·부감독 횟수도 각각 균등하게 맞춤
- 제외: 담임은 자기 학급 제외, 출제 교과 교사는 그 과목 시험실만 제외(설정에서 그 교시 전체로 변경 가능, 처음값은 시험실만), 개인 사정 불가 교시 반영
- 하루 한도: 정감독+부감독 합쳐 최대 3교시(두 학년 동시 시험이면 필요 인원이 교사의 약 88%라 2교시로는 불가능함). 자율은 따로 세며 처음값 2교시(설정값)
- 시험 기간 전체에 고르게 분산함
- 같은 학급에 같은 교사가 반복해서 들어가지 않게 함. 정·부감독 같은 짝의 반복도 피함
- 이력 누적: 중간고사 점수를 기말고사에 이어받아 누적 점수가 낮은 교사에게 더 배정함. 첫 시험은 모두 0점에서 시작함
- 규칙 때문에 배정이 불가능하면 어떤 규칙이 걸렸는지 알리고, 임시로 풀지 담당자가 선택함

## 5. 사용 방식
- 담당자: 공용 담당자 비밀번호로 편성·수정함 (서버에서만 확인, 틀린 횟수 제한)
- 교사: 로그인 없이 이름을 선택하면 자기 감독표, 전체 시간표, 교사별 점수 합계를 봄
- 수정: 담당자가 칸을 눌러 직접 변경. 규칙에 맞는 교사를 누적 점수가 낮은 순으로 추천함
- 칸 잠금: 잠그지 않은 칸만 다시 자동 편성함. 발표 뒤 바뀐 칸은 표시함
- 교사 간 교환 신청은 이번 범위에서 제외함

## 6. 저장과 배포
- 저장: Supabase `hanja-relay-diary` 프로젝트, 테이블 이름은 `exam_` 접두어. 기존 테이블은 건드리지 않음
- 이유: 무료 요금제 활성 프로젝트 2개 제한 때문에 새 '시험' 프로젝트를 만들 수 없음
- 저장 정보: 교사 이름, 담임 학급, 불가 교시, 배정 결과. 학생 정보는 없음
- 배포: Vercel, 현재 저장소(Next.js)에 추가함
- 공개 범위: 학교 안에서만 쓰는 링크. 모든 테이블에 접근 제한(RLS)을 적용함

## 7. 출력
- 전체 시간표 인쇄·PDF
- 교사별 감독표 인쇄·PDF
- 엑셀(CSV) 내려받기
- 휴대폰 캘린더 연동은 제외함

## 8. 만드는 순서
1. 테이블 설계, 교사 명단·시간표 입력 화면, 설정값
2. 자동 편성과 규칙 검사
3. 교사 조회 화면, 수정·추천·잠금
4. 출력과 이력 누적
